## Description of folders
Code/
The Code/ folder contains the R scripts used to process data, perform statistical analyses, train machine-learning models, generate figures, and save numerical outputs.

Data/
The Data/ folder contains processed input files used by the R scripts. The complete version of this folder is available in Zenodo. It includes soil properties, amplicon feature tables, genome-informed microbial trait files, target-gene catalogues, and metagenome-derived gene count files.

Result_output/
The Result_output/ folder contains saved R objects generated by the analysis scripts. These files include processed model outputs, microbial composition results, genome-informed trait outputs, phylogenetic analysis results, within-taxon trait-variation results, XGBoost model outputs, SHAP-related results, and metagenomic gene-abundance differential analysis results.

All files in Result_output/ were generated and saved by the scripts in Code/. Some scripts call these saved outputs to avoid rerunning computationally expensive steps.

## Data availability
The complete processed dataset is deposited in Zenodo: https://doi.org/10.5281/zenodo.20849331

Only relatively small supporting data files are included in this GitHub repository. The full dataset, including larger processed data files and complete analysis inputs, should be downloaded from Zenodo when reproducing the full analyses.

Amplicon sequencing data: CNP0008410
Shotgun metagenomic sequencing data: CNP0008455

## Description of scripts
The R scripts are stored in the Code/ folder and are numbered according to the main analysis workflow. The script names indicate the corresponding analysis and the figures or supplementary tables generated by each script.

## Running the scripts
Each script can be run independently when the required input files and, where applicable, the required saved objects in Result_output/ are available.

For a complete rerun from the beginning, the scripts should be run in numerical order:

01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11

For reproducing figures and tables more quickly, users may use the saved outputs already provided in Result_output/.

## Software environment
The analyses were conducted in R. The manuscript reports analyses using R v4.5.1.

Required R packages are loaded within the individual scripts. Users should install missing packages before running each script.

## Reproducibility note
This repository is intended to be used together with the complete Zenodo dataset. Because only small supporting data files are stored in GitHub, reproducing the full workflow may require downloading the complete dataset from Zenodo and placing the files under the expected folder structure.
